# 🚗 CO₂ Emissions Predictor

A machine learning project that uses historical vehicle CO₂ emissions
data to predict CO₂ emissions based on vehicle and fuel characteristics.

## 🚀 Live Demo

**Try the deployed application:**\
https://co2-emissions-predictor-pk4wynfapgoeh3vzcseffx.streamlit.app/

## 📌 Project Overview

This project explores historical vehicle CO₂ emissions data and builds a
**Linear Regression** model to predict CO₂ emissions.

The trained model was packaged into a preprocessing and prediction
pipeline and deployed as an interactive **Streamlit** web application.

## 📊 Model Performance

-   **R²:** 95.71%
-   **Adjusted R²:** 95.49%
-   **MAE:** 8.70 g/km
-   **RMSE:** 12.44 g/km
-   **5-Fold Cross-Validation Mean R²:** 94.74%

## 💡 Key Insight

The analysis showed strong relationships between vehicle
characteristics, fuel consumption, and CO₂ emissions. The resulting
model provides a practical way to estimate emissions from vehicle
characteristics.

## ▶️ How to Run Locally

Clone the repository and install the required packages:

``` bash
pip install -r requirements.txt
```

Run the Streamlit application:

``` bash
streamlit run app.py
```
